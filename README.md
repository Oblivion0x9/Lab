# 🧪 Systems, Networking & Security Lab

Welcome to my personal technical laboratory. This repository serves as a centralized workspace for independent research, low-level programming, system architecture exploration, and practical cybersecurity experiments conducted outside of my standard university coursework.

---

## 🎯 Focus Areas & Topics

The projects and prototypes inside this repository cover several core areas of computer science and security:

- **Systems Programming:** Custom command-line interpreters (shells), process management, memory handling, and OS-level interactions in C/C++.
- **Networking & Protocols:** Socket programming, packet analysis, custom network utilities, and client-server architectures.
- **Cybersecurity & Defensive/Offensive Concepts:** Security testing prototypes, system hardening experiments, and Proof-of-Concept (PoC) scripts developed in controlled lab environments.
- **Automation & Tooling:** Custom scripts and utilities built to streamline workflows on Linux environments.

---
